One town. One Pokémon per project.

When you run multiple Claude Code sessions at once, tracking which window needs attention takes time. Pokémon Agents maps each session to a character in a top-down town so you can check session states visually.

See status at a glance

Spot who is running, who finished, and who needs input. A session waiting on a decision walks up with an exclamation mark above its head.

Tie growth to actual code

Each project links to a persistent Pokémon. It gains levels, earns badges, and evolves through the Gen 1 and Gen 2 trees based on your git commits, pull requests, and passing test runs.

Respond directly from the game

Reply to waiting agents, jump to active terminals, start new tasks, and review activity logs without leaving the town view.

Run it · about two minutes

Free, open source, yours.

You'll need macOS, Node 22 and Claude Code. Clone the repo and run three commands — the first start reads your Claude history once, then just follows what's new. Everything stays on your machine. Full guide on GitHub →

# clone, then:
npm install
npm run setup # git hooks + fetch the assets
npm start # open http://127.0.0.1:7880
